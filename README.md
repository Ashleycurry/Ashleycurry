## About Me

> **Embedded Software & LLM Applications Engineer**  
> *Turning complex hardware into smart solutions.*

I design and ship software where deterministic firmware meets applied AI — register-level drivers and RTOS scheduling on one side, retrieval pipelines and LLM tooling on the other.

- **Embedded systems** — bare-metal and RTOS firmware with predictable timing, bounded memory, and clean hardware abstraction boundaries.
- **Applied AI** — retrieval-augmented pipelines built around answer quality, latency, and cost, not demos.
- **Engineering practice** — explicit interfaces, documented failure modes, and validation treated as product features.
